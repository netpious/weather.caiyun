# weather.caiyun

| 内容       | 说明                                                                |
| ---------- | ------------------------------------------------------------------- |
| 实况       | 温度 / 体感 / 露点 / 湿度 / 风 / 气压 / 能见度 / 云量               |
| 降水 | 未来 2 小时                           |
| 逐小时     | 16小时                                        |
| 逐日       | 7天                              |
| 气象预警   | 带类型与级别，新预警弹通知（可关）                                  |
| 云图       | 降雨实况、降雨预报、降雨动图、空气质量实况、空气质量动图            |

## 地图

| 图层 | 接口                   | 范围                                                                                                                                    |
| ---- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 降雨 | `v1/radar/fine_images` | 每帧自带 bounds（站点周边约 5°）                                                                                                        |
| 空气 | `v1/aqi/images`        | 栅格是整块亚洲（11 像素/经度），按网页地图的视窗裁一块
彩云地图页本身就加载高德（`webapi.amap.com/maps`，key 是彩云的），所以底图同源。 |

## 开发

```bash
python tools/test_caiyun.py                      # 离线断言，不联网、不需要 Kodi
python tools/live_check_maps.py 116.4 39.9 1 4   # 联网跑云图 + 生活指数，出预览图
python tools/build_zip.py weather.caiyun         # 打包
```
